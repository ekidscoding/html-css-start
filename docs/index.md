# HTML

## Місце HTML серед інших Web-технологій

HTML (HyperText Markup Language) - це мова розмітки веб-сторінок.

### Варто зазначити що HTML

- не є мовою програмування, тому формально HTML файл не можна назвати програмою

- є спеціальним текстовим форматом, що "розшифровується" (парситься) веб-браузером (Chrome, Firefox тощо)

- виник в епоху раннього Інтернету, коли багатьох інших сучасних Web-технологій просто не існувало навіть в зачатку

- легко вивчити в основі але потрібен час, щоб опанувати більш сучасні підходи

- може зрозуміти кожен, хто витратив бодай 10 годин на вивчення
